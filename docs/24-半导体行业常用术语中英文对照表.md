## 11. 易混术语说明

- **Mask 与 Reticle**：两者中文都常译"掩模版"，严格说 Reticle 是步进/扫描机上使用的母版，Mask 是通用称法；产线口语多混用，表中分列以便区分。
- **Seed Crystal 与 Seed Layer**：前者是拉单晶用的"籽晶"，后者是电镀/溅射互连时的"籽晶层"，中文都带"籽晶"但属不同工序，已分置类别 1 与类别 2。
- **CMP、AOI、Overlay 的归类**：这类跨工序高频词各只归入其最典型的一段——CMP 在平坦化（§6）、AOI 与 Overlay 量测在检测量测（§7）——避免重复列出。
