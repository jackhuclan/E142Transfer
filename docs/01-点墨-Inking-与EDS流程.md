# 01 点墨（Inking）与 EDS 流程

[返回索引](./README.md)

## 一句话定义

**点墨（Inking / Ink Dot）**：在晶圆电性测试（CP / EDS，Electrical Die Sorting）的最后，用特殊墨水在**不良 die 上点一个标记点**，使坏片能被肉眼或机器视觉识别，从而在封装前被剔除。它是"测试结果"和"物理分拣"之间的那座桥。

严格说，点墨不是一道"加工工艺"，而是 EDS 收尾时的**分选标记动作**。

## 在 EDS 流程中的位置

EDS 有五道工序，点墨是**最后一步**：

1. 晶圆来料检查
2. 探针测试 / Pre-Laser 高低温测试
3. 激光修复（针对可修复的失效）
4. Final Test 终测
5. **点墨（Inking）** ← 本文主题

点墨之后，晶圆还要经过**烘烤固化 + QC 检查**，才流入封装。

## 点墨的对象

被点墨的 die 有三类：

- 高低温测试（Pre-Laser）判定 fail 的 die；
- 激光修复后终测（Final Test）仍不通过的 die；
- 晶圆边缘未完整成形的 Dummy die。

标记通常打在 die 中央，避开焊盘与有效区。后续 die attach / 分选设备上的视觉系统识别墨点并跳过；少数场景仍靠人眼。

## 为什么要做

核心目的是**成本拦截**。坏 die 一旦流进封装，就要白白消耗基板、键合线、塑封料、测试机时间和人力。在最靠近源头的地方标出来，后续工序只处理良品，材料、设备、时间和人力都省下来。

它还有第二层价值：让不良分布可视化，反向给 FAB 和设计团队提供良率反馈。

## 关键演变：从"实体墨点"到"数据墨点"

这是理解现代点墨最重要的一点。传统上真的往 die 上喷墨，但墨水本身有污染风险、需要固化，且随着 die 越来越小越来越难打。如今主流已经**"只点数据不点墨"**：

| 维度 | 实体点墨 (Ink Dot) | 数据点墨 (Wafer Map / Substrate Mapping) |
|---|---|---|
| 载体 | 晶圆上的墨点 | 晶圆图文件里的 bin 分类 |
| 传递 | 随晶圆物理流转 | 通过网络传给 die attach 设备 |
| 拾取依据 | 视觉识别墨点后跳过 | 只读 good bin，按坐标拾取 |
| 适用 | 低产量、需目视确认、部分特殊流程 | 主流量产，尤其高良率、小 die |

英文资料里甚至直接说 "today the inking process is performed using data only."

所以"点墨"在今天更多是一个**逻辑概念（给坏片打标记并剔除）**，实体墨水只是它的一种实现手段。

## 与三映射的对应

"给每个 die 打标记 → 形成可传递的映射图 → 下游按图分拣"这个范式，与 PL 检测上位机的 **EL / PL / AOI 三映射**本质同构：每一张 mapping 就是一个 wafer map，每个 die 的 pass/fail/bin 就是"数字墨点"。区别只是判定依据从电性测试换成了光学/发光特征。
